## How to Run

### 一键启动（推荐）

```bash
# Linux / macOS
./start.sh

# Windows
start.bat
```

启动脚本会引导你：
1. 选择运行方式（Docker 或 本地 Python）
2. 输入今日日期和前日日期
3. 自动检查环境并执行

### Docker 启动

```bash
# 构建并启动容器
docker-compose up --build -d

# 查看日志
docker-compose logs -f enterprise-checker

# 停止容器
docker-compose down
```

### 本地启动

```bash
# 进入 backend 目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 运行脚本（使用环境变量配置日期）
TODAY_DATE=20251214 PREVIOUS_DATE=20251213 python check_enterprise.py
```

# 企业信息批量检查工具

## 项目简介

本项目是一个企业信息合规检查工具，用于自动化检查企业信息批量查询列表中的各项合规状态，包括登记状态、黑名单状态、涉诉情况、营业期限等，并支持与前一天数据进行比较，检测关键信息变更。

## 功能特性

- 自动识别指定日期的 Excel 文件
- 检查企业登记状态、黑名单状态等合规项
- 检查营业期限是否有效
- 与前一天数据比较，检测法定代表人、经营范围等关键信息变更
- 生成详细的检查报告

## 配置说明

### 默认路径

| 运行方式 | 默认路径 | 说明 |
|---------|---------|------|
| 本地运行 | `./Downloads` | 项目根目录下的 Downloads 文件夹 |
| Docker 运行 | `./Downloads` | 挂载到容器内 `/app/Downloads` |

### 修改数据目录

#### 本地运行

方式一：修改 `backend/check_enterprise.py` 顶部配置区域：

```python
CONFIG = {
    "base_path": os.environ.get('BASE_PATH', './Downloads'),  # 修改这里
    ...
}
```

方式二：通过环境变量：

```bash
BASE_PATH=/your/custom/path python backend/check_enterprise.py
```

#### Docker 运行

修改 `docker-compose.yml`：

```yaml
volumes:
  - ./Downloads:/app/Downloads        # 默认：项目下的 Downloads 目录
  - ~/Downloads:/app/Downloads        # 方式1：用户主目录的 Downloads
  - /path/to/your/dir:/app/Downloads  # 方式2：任意绝对路径
environment:
  - BASE_PATH=./Downloads             # 容器内路径保持一致即可
```

### 环境变量配置

| 变量名 | 默认值 | 说明 |
|-------|-------|------|
| `BASE_PATH` | `./Downloads` | Excel 文件所在目录 |
| `TODAY_DATE` | 自动获取当天 | 今日日期，格式 YYYYMMDD |
| `PREVIOUS_DATE` | 空 | 前一天日期，用于比较检查 |
| `OUTPUT_REPORT` | 空 | 输出报告路径，空则自动生成到数据目录 |
